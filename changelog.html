Release history

Changelog.

Every Vibe in Color release records its user-visible changes, format validation, and maintainer-tested ChatGPT macOS compatibility.

Version 0.4.0

August 1, 2026

Bring every palette with you.

  • Import one or many named codex-theme-v1 values into the custom-theme library.
  • Tag each custom theme to one or several vibes and change those tags later without duplicating it.
  • Give imported and library-created themes a neutral home in For Any Mood until more specific tags are chosen.
  • Preserve syntax, contrast, window-opacity, semantic-color, and installed-font settings across import and export.
  • Update repeated imports in place, migrate existing custom themes without changing their identity, and keep batch imports atomic.
  • Add an adaptive chameleon scene for For Any Mood and preserve every vibe illustration’s aspect ratio while resizing.
  • Start font searches at the first matching result, then restore the active font when search is cleared.

Compatibility: Maintainer-tested with the latest available ChatGPT for macOS release, version 26.727.51351, build 6119. All 300 bundled exports and the expanded custom-theme import cases also passed the automated codex-theme-v1 contract validator.

Version 0.3.2

July 29, 2026

Every font. Your colors.

  • Show every installed font in the code-font picker, including proportional families.
  • Let people explicitly keep a below-recommended-contrast palette as a personal theme.
  • Offer one-click readability adjustment that changes only the color role causing the issue.
  • Replace contrast jargon with plain-language lighter-or-darker guidance and optional technical details.
  • Validate the complete codex-theme-v1 structure for every bundled theme export.

Compatibility: Maintainer-tested with the latest available ChatGPT for macOS release, version 26.721.41059, build 5848. All 300 bundled exports also passed the automated codex-theme-v1 contract validator.

Version 0.3.1

July 27, 2026

One hundred new ways into your vibe

  • Add ten new research-seeded themes to every vibe, expanding the built-in catalog from 200 to 300.
  • Preserve every original theme while keeping the complete catalog evenly split between 150 light and 150 dark themes.
  • Qualify all 100 additions for readability, vibe-specific palette constraints, and visual distinctness from the existing catalog and one another.

Compatibility: The codex-theme-v1 import format is unchanged from version 0.3.0, last tested with ChatGPT for macOS 26.715.72359, build 5718.

Version 0.3.0

July 26, 2026

Typography that follows your theme

  • Remember a separate interface and code font pair for every theme.
  • Restore both fonts automatically whenever you return to a theme.
  • Reveal the active font when switching themes or typography targets.
  • Keep font scrolling, selection, and Interface/Code switching responsive in large installed font libraries.

Compatibility: The codex-theme-v1 import format is unchanged from version 0.2.0, last tested with ChatGPT for macOS 26.715.72359, build 5718.

Version 0.2.0

July 25, 2026

Your vibe, your palette

  • Create dark or light themes inside any vibe with a readable starting palette.
  • Enter exact background, foreground, and accent hex values or use the built-in color picker.
  • Rename and edit custom themes, then delete old themes directly from their row.
  • Keep custom palettes, the selected theme, and its vibe across app launches.

Compatibility: Tested with ChatGPT for macOS 26.715.72359, build 5718.

Version 0.1.1

July 22, 2026

Reliable code-font search

  • Update code-font results immediately after clearing the interface-font search and switching typography targets.

Compatibility: Tested with ChatGPT for macOS 26.715.72359, build 5718.

Version 0.1.0

July 22, 2026

The first public release

  • Browse 200 original themes across ten vibes, split into 100 light and 100 dark themes.
  • Search themes by name, vibe, or palette family and save favorites.
  • Preview prose, chat, code, diffs, interface fonts, and code fonts.
  • Copy a complete codex-theme-v1 value into the ChatGPT macOS app.
  • Ship as an Apple-notarized, stapled, arm64 app for macOS 14 and later.
